개발하는 방식

단순히 기능을 구현하는 것보다 문제를 이해하고, 실제 사용 환경에서 오래 사용할 수 있는 구조를 고민합니다.

문제를 소프트웨어로 해결합니다.

ERP, POS, 외부 API 연동과 같은 업무 시스템부터 RAG, AI 챗봇, MCP 기반 AI 시스템까지 다양한 환경에서 반복적인 업무를 줄이고 개발 생산성을 높이는 방법을 고민하고 실제로 구현해왔습니다.

언어와 아키텍처에 대한 기본기를 바탕으로 프로젝트를 설계하고 문제를 구조적으로 분석합니다. 하네스 엔지니어링과 Claude Code를 적극 활용해 빠르게 만들고, 정확하게 이해하며, 높은 품질의 결과물까지 만들어냅니다.

직접 만들고, 실제로 배포합니다.

개인적으로도 모바일 애플리케이션과 게임을 기획하고 개발하며, 앱스토어 배포와 서비스 운영까지 경험하고 있습니다.
